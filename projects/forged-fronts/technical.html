Context & my role

As Technical Director at Bowler Hat Interactive, I established the project's technical foundation and coordinated developers around a shared gameplay framework. My responsibilities covered hands-on implementation and organizing a team that needed clearer technical direction.

What I personally built

Movement, FPS, and camera systems

I personally designed and implemented movement, first-person shooter, and camera systems from scratch, using a modular structure so developers could build reusable gameplay features.

Custom C++ asynchronous asset loading

I built a generalized loading layer that routes loaded assets to their intended actor using a payload tag, actor ID, or actor name. It provides a failure output so the calling system can respond when a load fails.

Team coordination

I established weekly meetings to clarify responsibilities, coordinate the next steps, and align development with studio priorities.

Ballistics & procedural animation

Built actorless C++ ballistics with asynchronous traces, wind and drag, material detection, bone-level hits, and Niagara Data Channels. Control Rig / CCDIK handles weapon grips, recoil, and sway.

How I built it

The loading layer adds project-specific request routing around asynchronous loading. This allows separate actor requests to be associated with their intended recipient.

The design uses soft references and releases references when assets are no longer needed so unused assets can become eligible for garbage collection. It uses validity checks before working with loaded objects. In this implementation, an object with a pending request waits for the load to finish before being destroyed.

The loader deliberately stays general: the calling gameplay system still handles casting and decides how to use the asset. Its failure output reports that a load failed without a detailed diagnostic reason.

The gameplay framework is modular so other developers can extend and reuse its systems. Weekly meetings make ownership and next steps clear across the team.

Results & impact

Delivered the movement, FPS, and camera framework in under two months. Developers use the shared core systems to build reusable gameplay features, supported by a coordinated development process.
